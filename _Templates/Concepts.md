## Créer une nouvelle note concept

1. Grep systématique de TOUTES les sources sur les mots-clés du thème
2. Extraire le savoir durable, laisser les chiffres datés dans les snapshots
3. Marquer les déductions ([D]/[H]) - ne jamais élever une interprétation au rang de fait
4. Lier : les sources, le snapshot daté, les projets concernés, les concepts voisins
5. Ajouter une ligne à ce tableau + à l'[[Accueil]]
